# Assets Folder

Thư mục này chứa các tài nguyên hình ảnh, sơ đồ thiết kế chiến dịch hoặc tệp mẫu hỗ trợ cho chiến dịch Google Ads.

Ví dụ:
- Ảnh chụp màn hình giao diện quảng cáo demo.
- Sơ đồ cấu trúc tài khoản (Campaign > Ad Group > Keywords & Ads).
- Các banner quảng cáo hiển thị đi kèm (nếu chạy Performance Max hoặc Display Ads).
