# Scripts Folder

Thư mục này chứa các kịch bản hoặc công cụ bổ trợ (Python/Node.js/Bash) dùng để tự động hóa quy trình phân tích quảng cáo cho skill.

Ví dụ:
- Công cụ cào thông tin nhanh (crawler) để trích xuất nội dung từ Landing Page.
- API scripts để kéo dữ liệu Keyword Search Volume tự động từ các công cụ như Google Keyword Planner hoặc SEMrush/Ahrefs.
